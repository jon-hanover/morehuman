# amorehumanfuture.org

Holding page for A More Human Future, served by GitHub Pages from the `docs/` folder of the default branch (`claude/happy-pasteur-dapleu`).

- `docs/index.html` is the page
- `docs/CNAME` sets the custom domain

## Publishing

Changes are merged into the default branch and made live by default, unless Jon asks to hold them for review. See `CLAUDE.md` for the steps.
